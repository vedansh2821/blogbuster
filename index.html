Hello, World

Posted on 2026-11-09 ·

Welcome to Blogbuster. This is a plain static blog: one HTML file, one stylesheet, and a small script. There is nothing to install and nothing to build — open index.html and it works.

To make it yours, edit this file, add a post in posts/, and update the list in script.js. See the README for the three-step guide.
